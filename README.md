# Duty-shift-swap


## Назначение

Обмен сменами дежурств: график, запросы обмена, подтверждение старшими, история замен.

## Роли и сценарии

Сотрудник (EMPLOYEE):
- просматривает свои смены и детали смены;
- выбирает свою свободную смену и смену коллеги, смотрит сравнение «Сейчас» и «После обмена», отправляет запрос;
- следит за исходящими запросами;
- принимает или отклоняет входящие запросы.

Старший (SENIOR):
- пользуется всеми экранами сотрудника;
- одобряет или отклоняет запросы, которые принял сотрудник;
- смотрит историю завершённых запросов;
- просматривает график всех смен (добавление, редактирование и удаление в ЛР1 только показаны в диалогах и не выполняются).

## Экраны

| Адрес | Экран | Кто видит |
|---|---|---|
| /login | Вход | все |
| / | Мои смены | вошедшие |
| /shift/:id | Детали смены | вошедшие |
| /select-shift?shiftId=... | Выбор смены для обмена | вошедшие |
| /swap-requests | Запросы обмена (исходящие и входящие) | вошедшие |
| /senior-queue | Очередь старшего: ждут решения, история, управление графиком | только SENIOR |

## Стек

React, TypeScript, Vite, MUI, React Router, npm.

## Запуск frontend

```
cd frontend
npm install
npm run dev
```

После запуска приложение доступно по адресу, который покажет Vite (обычно http://localhost:5173/).
